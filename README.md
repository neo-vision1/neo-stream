# Neo Stream

Plataforma da Neo Vision para transmissão e controle remoto de câmeras e drones.

## Módulo disponível

- [Camera Agent](camera-agent/README.md): controle PTZ remoto de câmera Intelbras por um Agent Windows, sem IP público, VPN ou port forwarding.

O vídeo permanece separado do controle e poderá ser integrado ao fluxo RTMP do projeto.
